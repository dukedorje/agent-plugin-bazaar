# Phase 4: Write Stories — Deferred Handoff

Story elaboration and bead materialization belong to
`update-sprint-plan-beads`. Keep this phase file as the handoff boundary.

Do not write story markdown or create story beads, including stubs. Legacy
story-writing flags do not bypass this boundary. Do not invoke sprint-to-beads
or revive a story size gate that writes outside the current change.

The handoff inputs are `SPEC_DIR/proposal.md`, spec deltas, optional
`SPEC_DIR/design.md`, and child ids recorded in `SPEC_DIR/tasks.md`.
Keep any pending story work unchecked there. Continue to Phase 5 without
claiming that stories have been generated or validated.
